## 2. Interdits

- **Aucun tiret long ni tiret moyen** (« — » « – ») : utiliser virgules, deux-points, parenthèses. Le trait
  d'union n'est permis que dans les mots composés (week-end, Entre-deux-Mers, Saint-Jean...).
- Rien d'inventé : pas d'avis, de notes, de nombre de clients, d'années d'expérience, de « n°1 », de
  « meilleur », de « le moins cher de Bordeaux », pas d'autres adresses ou agences, pas de partenaires,
  pas de concurrents cités, pas de chiffres hors du paragraphe 1.
- Ne pas écrire « démonstration », « démo ». Ne jamais utiliser les mots « comptable » ou « comptabilité ».
- Pas de promesse non tenue (livraison hors 25 km, ouverture le dimanche, sans caution, etc.).
- Pas de pages « porte d'entrée » creuses : chaque page apporte des informations utiles et différentes.

## 3. Style

Français impeccable, vouvoiement, ton premium mais simple et concret (une agence locale sérieuse qui
aide à choisir). Phrases claires, paragraphes courts (2 à 4 phrases), listes à puces quand c'est utile,
chiffres exacts du paragraphe 1. Mot-clé principal naturellement dans le H1, le title, la description,
la première phrase et au moins un H2 ; variantes et synonymes (louer, loueur, location de véhicule,
agence de location, Bordeaux Métropole, Gironde, rive droite...). Nombres à la française : 39 €, 1 500 €,
3,5 tonnes, 20 m³, 8 h 30.

## 5. Format de sortie (fichiers JavaScript, dans `source/seo/content/`)

Chaque fichier ajoute ses pages à une variable globale, sans rien d'autre :

```js
/* Contenu SEO : <sujet> */
window.SEO_PAGES = (window.SEO_PAGES || []).concat([
  {
    path: '/location-voiture-bordeaux',        // chemin exact de la page
    kind: 'landing',                           // 'landing' | 'vehicle' | 'guide' | 'page'
    title: '...',            // balise title : 45 à 60 caractères, finit par « | PRISMA » si la place le permet
    description: '...',      // meta description : 140 à 158 caractères, incitative, avec le mot-clé
    h1: '...',
    eyebrow: '...',          // sur-titre de 2 à 4 mots
    lead: '...',             // chapeau de 2 ou 3 phrases (texte simple, sans HTML)
    vehicles: ['v-clio'],    // ids des véhicules à présenter en cartes (landings ; [] si aucun)
    sections: [              // 4 à 7 sections ; html autorisé : p, ul, ol, li, strong, em, a (liens internes du §4)
      { h2: '...', html: '<p>...</p>' },
    ],
    faq: [ { q: '...', a: '...' } ],   // réponses en texte simple (une phrase ou deux, <a> autorisé)
    related: ['/location-utilitaire-bordeaux'], // 3 à 5 chemins du §4
  },
]);
```

Pour les guides, ajouter `date: '2026-09-29'` et `minutes` (temps de lecture estimé).
Pour les fiches véhicules, `path` = chemin de la fiche et ajouter `id: 'v-clio'` et `ideal: [...]`
(3 à 5 usages courts). Apostrophes : utiliser ’ dans les textes, et des guillemets simples '...' en JS
(échapper si besoin) ou des gabarits `...`. Vérifier la syntaxe avec `node -e "require('./fichier.js')"`
(définir `global.window = global` avant) et qu'aucun « — » ni « – » n'apparaît.
